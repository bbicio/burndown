## Global Constraints

- Backend command, verbatim: `docker exec "$API_CONTAINER" node --test 'src/**/*.test.js'` — single-quoted glob, placed after `wait_healthy "$API_CONTAINER"` and before `$COMPOSE --profile test run --rm --use-aliases test`.
- `scripts/run-tests.sh` keeps: lock, pre-cleanup, `trap cleanup EXIT`, no host ports, migrations in one `psql` session with `-v ON_ERROR_STOP=1` and the `\echo applying …` marker, the image hash.
- **Never** run a command against the main stack (`pdash-db`, `pdash-api`, project `burndown`). `scripts/run-tests.sh` uses project `pdash_test` only. Run it from the worktree root, with `.env` copied from the main checkout (never committed).
- Re-entry scope, verbatim (English form of Spec §2): `git diff <red-HEAD>..HEAD -- '*.md'`.
- B-411 template addition, verbatim: `(first: <verdict> → <command>)`.
- B-412 wording, verbatim: `When run outside \`/finish-cycle\`, run`.
- Every file edit goes through the Edit tool, never `node -e` or `sed` with quoted text.
- Spec and Plan are frozen once execution starts (PROCESS.md §1).

## Review Focus

1. **The glob reaches every backend test file** — the container run must report at least the 398 tests `pdash-api` reported for `src/*/*.test.js` on 2026-11-10. Checked in Task 1 Step 3.
2. **A backend red stops the script before `test-api.js`, and the stack is still torn down** — `docker ps -a --filter name=pdash-api-test` empty afterwards. Checked in Task 1 Step 4.
3. **The container runs the worktree's code, not the main checkout's** — the deliberately broken assertion lives only in the worktree; Task 1 Step 4 proves it by turning the run red.
4. **Env differences in `pdash-api-test`** (`ANTHROPIC_BASE_URL=http://test:4010`, `ANTHROPIC_API_KEY=test-key`) must not break `src/services/llm.test.js`. Checked by Task 1 Step 3 being green.
