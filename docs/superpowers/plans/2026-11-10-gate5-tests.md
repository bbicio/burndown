# Gate 5 tests — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gate 5 runs its tests once, at step 3, sized to the diff: `/sync-docs` stops running `npm test` inside `/finish-cycle`, a diff of `.md` plus `scripts/**/*.test.js` runs the subset, a red step 3 re-enters at step 3, and the report records what ran.

**Architecture:** `scripts/gate5-scope.mjs` gains a third verdict, `docs-and-script-tests`, decided on paths only. Everything else is text in `.claude/commands/finish-cycle.md`, `.claude/skills/sync-docs/SKILL.md`, `docs/superpowers/PROCESS.md`, `CLAUDE.md` and `ARCHITECTURE.md`.

**Tech Stack:** Node ESM script under `scripts/`, vitest, Markdown command/skill files.

**Spec:** `docs/superpowers/specs/2026-11-10-gate5-tests-design.md`
**Branch:** `gate5-tests`
**Risk class:** standard — process files (`.claude/`, `scripts/`, `docs/superpowers/PROCESS.md`), no high-risk category of §6.1b

The tasks are sequential (Task 2 cites Task 1's token; Task 4 describes Tasks 1-3), not independent.

## Global Constraints

- Tokens, verbatim: `docs-only`, `docs-and-script-tests`, `other`.
- `docs-and-script-tests` = non-empty path list; every path ends in `.md`, is exactly `js/lib/test-cases-parse.test.js`, or matches `scripts/**/*.test.js` (starts with `scripts/`, ends with `.test.js`); at least one path of the last kind (Spec §3.1).
- Subset command, verbatim: `npx vitest run scripts/ js/lib/test-cases-parse.test.js`. Full suite: `npm test`.
- Step 5's pre-authorised path still names only `docs-only` (Spec §4).
- Report template line, verbatim (English form of Spec §4): `**Gate 5 tests:** <verdict> → <command> ×<N> (<green on first run | red, then green>)`.
- Every file edit goes through the Edit tool, never `node -e` or `sed` with quoted text (Gate 5 preamble; memory: shell drops backslashes).
- Spec and Plan are frozen once execution starts (PROCESS.md §1).

## Review Focus

1. **A `scripts/` non-test file** (`scripts/x.mjs`, `scripts/lib/live-docs.mjs`) next to `.md` must be `other`, not the new verdict. Test in Task 1.
2. **A `js/lib/*.test.js` other than the parse test** (a product guard lowered by `/sync-docs`, seen twice since 2026-10-09) must stay `other`, so it still runs `npm test`. Test in Task 1.
3. **A diff of only `js/lib/test-cases-parse.test.js` plus `.md`** must stay `docs-only` (not the new verdict), or it would lose pre-authorisation. Existing test, kept.
4. **A nested `scripts/lib/x.test.js`** must count as a script test. Test in Task 1.
5. **A path merely containing `scripts/`** (`docs/scripts/x.test.js`) must not count. Test in Task 1.
